Да, в Cloud.ru есть возможность **вайб-кодинга** (vibe coding) с помощью сервиса **Foundation Models**! 

## Что это такое?
Вайб-кодинг — это подход к программированию, когда вы описываете задачу на естественном языке (промпт), а AI-модель генерирует код. Вы можете создавать приложения, не пишa код вручную.

## Как начать?
1. **Подключите Foundation Models в VS Code** — используйте плагин для работы с AI-моделями
2. **Выберите модель** для программирования:
   - `zai-org/GLM-4.6` (рекомендуется)
   - `Qwen/Qwen3-Coder-480B-A35B-Instruct`
   - `openai/gpt-oss-120b`

## 💰 Это бесплатно?
**Да, частично!** 
- Есть **бесплатные модели** в режиме **Public Preview** — ими можно пользоваться бесплатно
- Платные модели стоят недорого: небольшое количество запросов обойдётся **не больше рубля**

## Пример использования
Вы можете создать Django-приложение, просто описав его в промпте:
```
Создай проект под названием "Рекордасьон" с использованием Django 5.2.7, Python 3.13 и базы данных SQLite...
```

AI-модель сама создаст структуру проекта, напишет код и настроит окружение.

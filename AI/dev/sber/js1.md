## 1

Вот **простой и бесплатный** способ разрабатывать и публиковать JS-приложения в Cloud.ru:

## 🎯 Простой путь (3 шага)

### Шаг 1: Создайте приложение с помощью AI (бесплатно)
1. Установите **VS Code**
2. Подключите плагин **Foundation Models**
3. Выберите **бесплатную модель** в режиме Public Preview
4. Опишите ваше приложение промптом, например:
   ```
   Создай простое браузерное приложение на чистом JavaScript:
   - HTML файл с формой для ввода текста
   - JavaScript для обработки данных
   - CSS для стилизации
   ```

### Шаг 2: Соберите Docker-образ (бесплатно)
```bash
# Соберите образ вашего приложения
docker build --tag <registry_name>.cr.cloud.ru/my-app . --platform linux/amd64

# Загрузите в реестр
docker push <registry_name>.cr.cloud.ru/my-app
```

### Шаг 3: Разверните в Container Apps (бесплатно)
1. В личном кабинете перейдите в **Artifact Registry**
2. Нажмите на образ → **Создать Container App**
3. Настройки:
   - **Порт**: 8080 (или ваш порт)
   - **vCPU/RAM**: минимальная конфигурация (0.1 vCPU – 256 MB)
   - **Минимум экземпляров**: 0 (когда нет запросов — не платите)
   - **Максимум экземпляров**: 1
   - **Публичный адрес**: включите

✅ **Готово!** Ваше приложение будет доступно по публичному URL.

## 💰 Почему это бесплатно?
- **Foundation Models**: бесплатные модели в Public Preview
- **Container Apps**: при масштабировании от 0 и минимальной конфигурации стоимость практически нулевая для простых приложений с низкой нагрузкой

## no docker 
**Да, можно!** И это даже проще и дешевле. Используйте **Object Storage** для хостинга статических сайтов.

## 🚀 Самый простой способ (без Docker)

### Что вам нужно:
1. **Создайте бакет** в Object Storage
2. **Загрузите файлы** (index.html, стили, скрипты)
3. **Включите хостинг сайта** — и готово!

### Пошагово:

**1. Создайте бакет**
- Перейдите в **Хранение данных → Object Storage**
- Нажмите **Создать бакет**
- Укажите название (станет частью URL)
- Максимальный размер: **15 ГБ** (бесплатно)

**2. Откройте публичный доступ**
- В настройках бакета откройте доступ к чтению для всех

**3. Загрузите файлы**
- Загрузите `index.html` (главная страница)
- Загрузите `error.html` (страница ошибок, опционально)
- Загрузите остальные файлы (CSS, JS, картинки)

**4. Включите хостинг сайта**
- Перейдите на вкладку **Настройка хостинга сайта**
- Главная страница: `index.html`
- Страница ошибки: `error.html`
- Нажмите **Сохранить**

### ✅ Результат
Ваш сайт будет доступен по адресу:
```
https://<имя-бакета>.s3-website.cloud.ru/
```

## 💰 Стоимость
- **Бесплатно до 15 ГБ** хранения (free tier)
- Дешевле Container Apps для простых сайтов

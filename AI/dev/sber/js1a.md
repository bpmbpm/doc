## 3

К сожалению, в Cloud.ru **нет встроенного онлайн-редактора кода**. Но есть простое решение, которое работает полностью в браузере:

## 🌐 Полностью в браузере (3 шага)

### Шаг 1: Напишите код в онлайн-редакторе
Используйте любой бесплатный онлайн-редактор:
- **[CodePen](https://codepen.io/)** — идеально для простых JS-приложений
- **[JSFiddle](https://jsfiddle.net/)** — простой редактор HTML/CSS/JS
- **[Replit](https://replit.com/)** — более мощный, с сохранением проектов

Просто откройте сайт в браузере и пишите код!

### Шаг 2: Скачайте файлы
Когда приложение готово:
- В CodePen: нажмите **Settings → Export → Download ZIP**
- В Replit: скачайте файлы проекта

### Шаг 3: Загрузите в Cloud.ru (через браузер)
1. Войдите в [личный кабинет Cloud.ru](https://console.cloud.ru)
2. Перейдите в **Хранение данных → Object Storage**
3. Создайте бакет (если ещё нет)
4. Откройте бакет → вкладка **Файлы**
5. Перетащите файлы (`index.html`, стили, скрипты) в окно браузера
6. Включите **хостинг сайта** на вкладке настроек

✅ **Готово!** Ваше приложение доступно по ссылке.

## 💡 Альтернатива: AI поможет написать код
Если не хотите писать код сами:
1. Откройте чат с **Foundation Models** в личном кабинете Cloud.ru
2. Напишите промпт: *"Создай HTML-файл с простым JS-приложением: калькулятор/список задач/игру..."*
3. AI сгенерирует код — скопируйте его в файл
4. Загрузите в Object Storage

## 📋 Итог
| Что делать | Где | Установка |
|---|---|---|
| Писать код | CodePen/JSFiddle (онлайн) | ❌ Не нужна |
| Генерировать код AI | Foundation Models (чат) | ❌ Не нужна |
| Опубликовать | Object Storage (веб-интерфейс) | ❌ Не нужна |

Всё работает в браузере, ничего устанавливать не нужно!

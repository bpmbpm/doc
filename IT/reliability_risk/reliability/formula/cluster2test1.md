- каждую формулу заключать в отдельный блок `$$ ... $$`;

- ставить закрывающий `$$` на отдельную строку;
- не размещать рядом с формулой HTML-теги;
- не помещать формулу внутрь блока кода;
- не использовать несколько независимых формул в одном блоке без выравнивания;
- использовать латинские имена математических переменных внутри LaTeX-команд;
- использовать `\mathrm{г}` только при необходимости.

## Если `\frac` все равно не отображается

Для диагностики можно временно заменить дроби на линейную запись:

```markdown
$$
K_g =
[\mu_{21}(\mu_{10}+\lambda_{01})]
/
[\mu_{10}\mu_{21}
+\lambda_{01}\mu_{21}
+\lambda_{01}\lambda_{12}]
$$
```

Если линейная запись отображается, а вариант с `\frac` нет, проблема связана с конкретным обработчиком формул, а не с математической моделью.

Также можно использовать самый простой вариант без `\mathrm` и кириллической буквы в индексе:

```markdown
$$
K_{g,st}
=
\frac{\mu_{21}(\mu_{10}+\lambda_{01})}
{\mu_{10}\mu_{21}
+\lambda_{01}\mu_{21}
+\lambda_{01}\lambda_{12}}
$$
```

Такой вариант обычно совместим с большим числом Markdown-рендереров. В GitHub `\frac` является стандартной LaTeX-конструкцией для дробей; поэтому сначала следует проверить отдельные строки с `$$`, а затем — возможные ограничения конкретного редактора или предпросмотрщика. [docs.github](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/writing-mathematical-expressions)

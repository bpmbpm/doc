На основе «Базовый промпт для модели надёжности простейшего кластера. Требования» добавь в модель состояния и повтори расчет Кг.
Новые состояния:
- S_failover (отказ)
- S_failback (отказ)

Окончание «_fail» добавлять не нужно, т.к. оно уже в названии узла. 

Переходы между состояниями:
- S0 → S_failover - отказ одного из двух работоспособных узлов и переход в стояние S_failover (начальная стадия переключения на резерв, интенсивность 2λ);
- S_failover → S1 — процедура failover и переход в работоспособную конфигурацию с одним рабочим узлом (финальная стадия переключения на резерв, интенсивность μ_failover);
- S1 → S2_fail — отказ оставшегося работоспособного узла, интенсивность λ;
- S1 → S_failback — процедура failback (начальная стадия ввода в строй отремонтированного узла, интенсивность μ)
- S_failback → S0 - финальная стадия ввода в строй отремонтированного узла (интенсивность μ_failback)
- S2_fail → S1 — восстановление одного из двух отказавших узлов (интенсивность μ).

Нет переходов:
- S1 → S0 
- S0 → S1

Для примера расчета Кгиспользуй средние значения времени: failover 30 секунд, failback 90 секунд. 
Отдельным блоком приведи наиболее правдоподобные операции для failover и failback.

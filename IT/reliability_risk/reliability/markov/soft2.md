## Онлайн-калькуляторы (бесплатно, без установки)

### Калькулятор марковского анализа надёжности (relind.ru)

Российский онлайн-калькулятор, специально созданный для расчёта показателей надёжности марковскими методами. Это, пожалуй, **наиболее целевой инструмент** под вашу задачу. [```1```](https://relind.ru/CalcGraph.html)

- **Что умеет:** графический редактор для построения марковского графа прямо в браузере (вершины = состояния, дуги = переходы с интенсивностями). Автоматически формирует матрицу интенсивностей и вектор начальных условий. Считает: коэффициент готовности (мгновенный и стационарный), коэффициент простоя, вероятность безотказной работы, параметр потока отказов, среднюю наработку до отказа, MTBF, среднее время восстановления, оперативный коэффициент готовности. [```1```](https://relind.ru/CalcGraph.html)
- **Тип цепи:** непрерывный марковский процесс (CTMC) — то, что обычно используется в задачах надёжности.
- **Доступ:** полностью бесплатно, прямо в браузере, без регистрации. На сайте также есть [подробное руководство](https://relind.ru/mHelp.html) с примером построения графа. [```48```](https://relind.ru/mHelp.html)
- **Плюсы:** не нужно ничего устанавливать, интерфейс на русском, считает именно то, что нужно — коэффициент готовности.
- **Минусы:** нет сохранения модели в файл, нет экспорта графа, ограниченные возможности по визуализации.

На том же сайте есть и **второй калькулятор** — для марковских моделей с доходами, который дополнительно считает эффективность, безопасность и коэффициент сохранения эффективности. [```47```](https://relind.ru/rwmCalc.html)

### Markov Chain Calculator (statskingdom.com)

Простой онлайн-калькулятор для дискретных марковских цепей. [```49```](https://www.statskingdom.com/markov-chain-calculator.html)

- **Что умеет:** считает n-шаговый вектор вероятностей и стационарное распределение. Показывает поглощающие состояния.
- **Плюсы:** быстро, наглядно, с пошаговым выводом.
- **Минусы:** только дискретные цепи; нет понятия «работоспособное/отказное состояние», поэтому коэффициент готовности придётся считать вручную — как сумму вероятностей работоспособных состояний.

### Wolfram Alpha

Можно задать матрицу переходов и запросить `stationary distribution` — Wolfram Alpha умеет находить стационарное распределение как собственный вектор матрицы с собственным значением 1. [```19```](https://www.wolframalpha.com/input/?i=markov+chain)[```20```](https://reference.wolfram.com/language/ref/DiscreteMarkovProcess.html)

- **Плюсы:** мгновенно, без установки.
- **Минусы:** только дискретные цепи, нет графического редактора, коэффициент готовности не рассчитывается напрямую — только вероятности состояний.

## Бесплатные десктопные программы

### Spicelogic Markov Chain Calculator

Бесплатная программа для Windows с графическим мастером построения цепи. [```57```](https://spicelogic.com/Products/markov-chain-calculator-31)

- **Что умеет:** построение цепи, расчёт стационарных вероятностей, анализ поглощающих цепей.
- **Плюсы:** полностью бесплатная, без рекламы, с GUI.
- **Минусы:** дискретные цепи, нет прямого расчёта коэффициента готовности.

### MarkovChainsCalculatorApp (GitHub, VeskoBot)

WPF-приложение для Windows с открытым исходным кодом. [```9```](https://github.com/VeskoBot/MarkovChainsCalculatorApp)

- **Что умеет:** интерактивное построение графа цепи, расчёт стационарных вероятностей и времени поглощения. Сохранение/загрузка модели в JSON.
- **Плюсы:** open-source, можно доработать под себя (C#/.NET).
- **Минусы:** только дискретные цепи, нет показателей надёжности «из коробки».

## Профессиональные пакеты (коммерческие)

### GRIF (TotalEnergies)

Профессиональный пакет для оценки надёжности, доступности и безопасности. [```6```](https://grif.totalenergies.com/en/products/markovian-package)

- **Модуль Markov:** графический редактор марковских графов, поддержка многофазных цепей. Для каждого состояния указывается, работоспособно оно или нет. Считает: вероятность состояния, накопленное время пребывания, **коэффициент готовности/надёжности системы**, интенсивность отказов, Lambda-эквивалент. [```6```](https://grif.totalenergies.com/en/products/markovian-package)
- **Движок:** ALBIZIA — собственный расчётный движок TotalEnergies.
- **Платформы:** Windows, Linux, macOS (Java 11).
- **Плюсы:** индустриальный стандарт для нефтегаза, авиации, ж/д; многофазные модели; учёт деградированных состояний.
- **Минусы:** коммерческая лицензия.

### ReliaSoft BlockSim (HBK)

Один из самых известных пакетов для RAMS-анализа. [```42```](https://help.reliasoft.com/articles/content/hotwire/issue183/hottopics183.htm)[```43```](https://www.hbkworld.com/de/products/software/analysis-simulation/reliability/blocksim-system-reliability-availability-maintainability-ram-analysis-software/markov-diagrams)[```45```](https://www.wilderisk.co.uk/software/reliasoft/blocksim/)

- **Модуль Markov Diagrams:** поддерживает дискретные и непрерывные марковские цепи. Графически строится диаграмма состояний, для каждого состояния задаются переходные интенсивности. Считает: **доступность (availability)**, надёжность, частоту отказов, стоимость. [```42```](https://help.reliasoft.com/articles/content/hotwire/issue183/hottopics183.htm)
- **Интеграция:** RBD, деревья отказов, анализ событий — всё в одном пакете.
- **Плюсы:** мощный, отраслевой стандарт; можно комбинировать марковские диаграммы с RBD и FTA.
- **Минусы:** коммерческая лицензия, цена существенная.

### Isograph Reliability Workbench

Ещё один крупный пакет с модулем марковского анализа. [```52```](https://www.isograph.com/software/reliability-workbench/markov-analysis-software/)[```51```](https://cognitivetech.co.in/isograph/)

- **Модуль Markov Analysis:** аналитический движок на численном интегрировании, поддержка многофазных моделей, интеграция с деревьями отказов и RBD. [```52```](https://www.isograph.com/software/reliability-workbench/markov-analysis-software/)
- **Плюсы:** точный аналитический расчёт (не симуляция), богатый набор стандартов (MIL-217, IEC 61508, ISO 26262 и др.).
- **Минусы:** коммерческая лицензия.

### RAM Commander (A.L.D. Group)

Пакет с модулем марковских цепей. [```8```](https://www.isditalia.it/software/reliability-software/markov/)[```11```](https://kit-e.ru/obzor-programm/)

- **Что умеет:** графический редактор диаграммы цепи, расчёт стационарного и нестационарного режимов, **доступность, недоступность, MTBF, MTTF, MTTR, надёжность**, экспорт в Excel/Word/HTML. [```7```](https://aldservice.com/Reliability-Products/markov.html)[```8```](https://www.isditalia.it/software/reliability-software/markov/)
- **Плюсы:** богатый набор метрик, хороший экспорт.
- **Минусы:** коммерческая лицензия.

## Программные библиотеки (для самостоятельной реализации)

### Python: NumPy / NetworkX / SciPy

Самый гибкий подход — написать расчёт на Python. [```30```](https://gist.github.com/jadhavpritish/c218d33902bd7862f7d271d7c563c198)[```32```](https://toknow.ai/posts/computational-techniques-in-data-science/stochastic_steady-state-probability_markov-chains_network-visualization/index.pdf)

```python
import numpy as np

# Матрица интенсивностей переходов (для CTMC)
# Q — генератор (infinitesimal generator matrix)
# Стационарное распределение: pi @ Q = 0, sum(pi) = 1

Q = np.array([
    [-1.0,  1.0],   # из состояния 0
    [ 0.5, -0.5],   # из состояния 1
])

# Решаем систему: Q^T @ pi = 0, sum(pi) = 1
A = np.vstack([Q.T, np.ones(Q.shape[0])])
b = np.zeros(Q.shape[0] + 1)
b[-1] = 1
pi = np.linalg.lstsq(A, b, rcond=None)[0]

# Коэффициент готовности = сумма вероятностей работоспособных состояний
# Допустим, состояние 0 — работоспособно, 1 — отказ
K_g = pi[0]
print(f"Стационарные вероятности: {pi}")
print(f"Коэффициент готовности: {K_g:.6f}")
```

- **Плюсы:** полный контроль, можно считать любые показатели, интеграция с визуализацией (NetworkX + Graphviz/Matplotlib).
- **Минусы:** нужно понимать математику и писать код.

### R: пакет markovchain

Пакет для работы с дискретными и непрерывными марковскими цепями. [```33```](https://www.researchgate.net/publication/318311147_Discrete_Time_Markov_Chains_with_R)[```34```](https://journal.r-project.org/articles/RJ-2017-036/)[```37```](https://cran.rstudio.com/web/packages/markovchain/vignettes/an_introduction_to_markovchain_package.pdf)

- **Что умеет:** создание объекта цепи, расчёт стационарного распределения, проверка эргодичности, статистические тесты, имитация траекторий. В пакете есть даже специальный файл `reliability.R` — демо по расчёту надёжности. [```36```](https://github.com/cran/markovchain/blob/master/demo/reliability.R)
- **Плюсы:** статистические методы, хорошая документация.
- **Минусы:** для коэффициента готовности нужно вручную суммировать вероятности работоспособных состояний.

### Mathcad

Классический подход для академических расчётов — аналитическое и имитационное моделирование марковских цепей с пошаговым выводом. [```12```](https://cyberleninka.ru/article/n/metodika-analiticheskogo-i-imitatsionnogo-modelirovaniya-diskretnyh-odnorodnyh-markovskih-tsepey-s-ispolzovaniem-mathcad)

- **Плюсы:** наглядность формул, привычный для инженеров интерфейс.
- **Минусы:** коммерческий, нет графического построения цепи.

## Что выбрать

- **Нужно быстро посчитать — прямо сейчас, без установки:** [relind.ru/CalcGraph.html](https://relind.ru/CalcGraph.html). Это единственный бесплатный онлайн-инструмент, который умеет строить граф цепи и сразу считать коэффициент готовности.
- **Нужен полный контроль, кастомные модели, интеграция с кодом:** Python + NumPy/SciPy. Стационарное распределение считается одной строкой, а коэффициент готовности — суммой вероятностей работоспособных состояний.
- **Промышленный проект, отчёт по ГОСТ:** GRIF, BlockSim или Reliability Workbench. Все три умеют многофазные марковские модели и считают доступность напрямую.

Если хотите, могу показать, как построить конкретную модель (например, дублированную систему с восстановлением) и посчитать для неё Кг — на relind.ru или на Python.

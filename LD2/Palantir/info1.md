In Foundry, the Ontology is the digital twin of an organization, integrating the organization's digital assets (datasets and models) into a coherent whole. The Foundry Ontology creates a complete picture of an organization’s world by mapping datasets and models to object types, properties, link types, and action types.
  - An object type defines an entity or event in an organization.
  - A property defines the object type’s characteristics.
  - A link type defines the relationship between two object types.
  - An action type defines how an object type can be modified."

Palantir последовательно раскрывает состав своей онтологии:
Object type — схема сущности или события реального мира.
Property — схема характеристики сущности или события.
Link type — схема отношения между двумя типами объектов.
Action type — схема набора изменений объектов, свойств и связей.
Причём последнее особенно интересно: действие здесь не просто фиксируется как знание, а становится исполняемой операцией над объектами."

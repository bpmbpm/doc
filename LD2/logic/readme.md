## link
- https://www.mathnet.ru/php/seminars.phtml?presentid=52817&option_lang=rus Логика HC: переводы, погружения и сложность фрагментов.  
- Аннотация: Рассматривается совместная логика задач и высказываний HC. Её естественными фрагментами являются классическая логика Cl, интуиционистская логика Int, модальные логики S4 и H4. Будет показано, как можно построить переводы между этими фрагментами и полиномиальные погружения, основанные на этих переводах. С помощью этих переводов доказывается PSPACE-полнота логик HC и H4. Будет показано, что позитивные фрагменты этих логик тоже PSPACE-полны, и что для PSPACE-трудности достаточно одной пропозициональной переменной. Предполагается обсудить связь логики HC с комбинированным исчислением высказываний и событий IB, предложенным В.А.Смирновым.

Логика предикатов первого порядка (FOL) и логика второго порядка — это формальные языки математической логики, которые различаются тем, по каким сущностям можно вести квантификацию (использовать кванторы ∀ «для всех» и ∃ «существует»).

Логика предикатов первого порядка (FOL)

- Кванторы: Разрешены только по предметным переменным (элементам области рассуждения), но не по предикатам или функциям.
- Пример: ∀x (Человек(x) → Смертен(x)) — «для любого объекта x, если x — человек, то x смертен».
- Основные свойства:
	- Полнота (теорема Гёделя о полноте) — все истинные семантически формулы могут быть выведены в рамках исчисления.
	- Компактность (теорема Мальцева) — если каждое конечное подмножество формул имеет модель, то и все множество имеет модель.
	- Теорема Лёвенгейма — Скулема — если теория первого порядка имеет бесконечную модель, то она имеет модели любой бесконечной мощности.
- Применение: Используется в математике, базах данных и искусственном интеллекте (например, язык Пролог).

Логика второго порядка

- Кванторы: Разрешены не только по предметным переменным, но и по предикатам и функциональным символам (то есть можно квантифицировать свойства и отношения).
- Пример: Принцип математической индукции можно записать одной формулой второго порядка:  
∀P ( P(0) ∧ ∀n (P(n) → P(n+1)) → ∀n P(n) )  
(здесь квантор ∀P стоит перед претикатом P).
- Основные свойства:
	- Богатая выразительность — позволяет формализовать понятия, которые не выразимы в FOL (например, конечность множества, транзитивное замыкание, стандартный ряд натуральных чисел).
	- Утрата хороших свойств — в отличие от FOL, логика второго порядка не обладает свойством полноты, не является компактной и на нее не распространяется теорема Лёвенгейма — Скулема.

Главные отличия

| Характеристика	| Логика 1-го порядка (FOL)	| Логика 2-го порядка |
|---|---|---|
| Кванторы по переменным	| Только по элементам (индивидам) |	По элементам и по предикатам/функциям |
| Полнота	| Да (теорема Гёделя)	| Нет |
| Компактность	| Да	| Нет |
| Теорема Лёвенгейма — Скулема	| Выполняется	| Не выполняется |
| Выразительность	| Стандартная (базовая)	| Избыточная (позволяет задать структуру чисел однозначно) |

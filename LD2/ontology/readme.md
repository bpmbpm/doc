## ontology
- Под онтологией будем понимать подробную таксономию (иерархию) классов (терминов), предикатов (отношений) и толковый словарь терминов. В таксономии только один тип связи "родитель", но для связи терминов требуются и другие (т.е. не только таксономия).  
- Онтология - это сами термины + Tbox (Rbox), включая отношения между терминами и их label \ description - описание, т.е. толковый словарь терминов. 
- Онтология = TBox (+ RBox). ABox не входит в онтологию. При этом База знаний = TBox (вкл. RBox) + ABox. 
### formal ontology
Возможно онтологию можно формализовать на русском \ английском языке, но не представляю как: там так много неоднозначности.  
Обычно онтологию формализуют на языках знаний, липс-подобных, дескрипционных логик (Description Logics, DL), Linked Data (OWL\манчестерский синтаксис) и т.п.

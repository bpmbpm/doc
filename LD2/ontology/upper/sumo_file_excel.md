## 1

Ниже — пошаговая инструкция, как из файлов SUMO (в формате SUO‑KIF) получить таблицу в Excel. Она рассчитана на человека, который уже работал с командной строкой, Python и JS (с учётом твоих прошлых задач).

---

## Шаг 1. Подготовь окружение

Тебе нужен Python (3.8+), Git и Excel (или LibreOffice Calc).

1. Установи Python, если нет: https://www.python.org/downloads/
2. Проверь, что он доступен в терминале:
   ```bash
   python --version
   # или на macOS/Linux:
   python3 --version
   ```
3. Создай папку для работы, например `sumo-excel`:
   ```bash
   mkdir sumo-excel
   cd sumo-excel
   ```

---

## Шаг 2. Скачай SUMO

В репозитории SUMO лежат файлы в формате SUO‑KIF.

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/ontologyportal/sumo.git
   ```
2. Зайди в папку:
   ```bash
   cd sumo
   ```
3. Основной файл с онтологией — `Merge.kif`. Именно его будем парсить.

---

## Шаг 3. Выбери и установи парсер для SUO‑KIF

Самый практичный вариант — Python‑парсер, который умеет выдавать CSV. Есть несколько реализаций на GitHub; для твоих задач (иерархия классов, отношения) подойдёт любой, который разбирает `isa`, `subclass` и т.п.

### Вариант А (самый простой): используй готовый скрипт-пример

Если не хочешь ставить сторонние пакеты, можно написать минимальный парсер под задачу. Ниже — готовый скрипт, который читает `Merge.kif` и выгружает в CSV:

```python
# parse_sumo_to_csv.py
import re
import csv
from pathlib import Path

kif_path = Path("Merge.kif")
out_path = Path("sumo_hierarchy.csv")

# Регулярки для извлечения отношений
# (isa X Y) → X является экземпляром Y
# (subclass X Y) → X является подклассом Y
isa_pattern = re.compile(r'\(\s*isa\s+([^\s)]+)\s+([^\s)]+)')
subclass_pattern = re.compile(r'\(\s*subclass\s+([^\s)]+)\s+([^\s)]+)')

rows = []
rows.append(["relation_type", "subject", "object"])

with kif_path.open(encoding="utf-8", errors="ignore") as f:
    text = f.read()

for m in isa_pattern.finditer(text):
    rows.append(["isa", m.group(1), m.group(2)])

for m in subclass_pattern.finditer(text):
    rows.append(["subclass", m.group(1), m.group(2)])

with out_path.open("w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(rows)

print(f"Готово: {out_path}")
```

Сохрани этот код в той же папке, где лежит `Merge.kif`, как `parse_sumo_to_csv.py`.

### Вариант Б (если хочешь полноценный парсер): поставь kifparser

Если позже понадобится разбирать более сложные аксиомы, ставь готовый пакет:

```bash
pip install kifparser
```

Но для простой таблицы (класс → подкласс) достаточно Варианта А.

---

## Шаг 4. Запусти парсер

Из папки, где лежит `Merge.kif` и `parse_sumo_to_csv.py`:

```bash
python parse_sumo_to_csv.py
# или python3, если нужно
```

После запуска появится файл `sumo_hierarchy.csv`.

---

## Шаг 5. Открой CSV в Excel

1. Открой Excel.
2. В меню: **Данные → Из текста/CSV** (или просто перетащи файл `sumo_hierarchy.csv` в окно Excel).
3. Убедись, что разделитель — запятая (это стандарт CSV).
4. Импортируй.

Теперь у тебя таблица с тремя колонками:
- `relation_type` — тип отношения (`isa` или `subclass`)
- `subject` — кто участвует первым (например, `Automobile`)
- `object` — к чему относится (например, `Device`)

---

## Шаг 6. Приведи таблицу к удобному виду

Для твоих задач (онтологии, SUMO, DOLCE, визуализация) лучше всего сделать «плоскую» иерархию «родитель → ребёнок».

1. Отфильтруй только строки с `subclass` — это и есть иерархия классов.
2. Переименуй колонки:
   - `subject` → `ChildClass`
   - `object` → `ParentClass`
3. Если нужны описания (комментарии), их придётся добавить вручную или отдельным шагом (SUMO хранит описания в отдельных аксиомах, их нужно парсить отдельно).

### Как быстро построить дерево в Excel

Есть два простых способа:

**Способ 1 (Power Query):**
- В Excel: **Данные → Получить данные → Из файла → Из CSV**.
- В редакторе Power Query отсортируй по `ParentClass`, затем по `ChildClass`.
- Можешь добавить вычисляемый столбец «Уровень» (Level) по количеству вхождений в цепочку родителей (это уже сложнее, но реализуемо).

**Способ 2 (простая сортировка и группировка):**
- Отсортируй по `ParentClass`.
- Вручную сделай отступ для подклассов (или добавь колонку `Level` и заполни её 1, 2, 3…).
- Сгруппируй строки по `ParentClass` (Данные → Группировать).

Так ты получишь наглядное дерево классов SUMO в Excel.

## Шаг 7. (Опционально) Добавь дополнительные типы отношений

Если тебе нужны не только `subclass`, но и другие связи (например, `instance`, `attribute`, `part`), допиши в скрипт новые регулярные выражения и добавь новые типы в колонку `relation_type`. Например:

```python
instance_pattern = re.compile(r'\(\s*instance\s+([^\s)]+)\s+([^\s)]+)')
```

И дальше — аналогично: найди все совпадения и запиши в CSV.

---

## Важные нюансы

- **SUMO большая.** Файл `Merge.kif` содержит десятки тысяч строк. CSV будет большим, но Excel обычно справляется с сотнями тысяч строк.
- **Не все аксиомы — это иерархия.** В SUMO много логических формул. Скрипт выше вытягивает только `isa` и `subclass`. Если понадобятся аксиомы с условиями (например, «если X, то Y»), их лучше не тащить в Excel, а обрабатывать в Turtle/RDF или в SigmaKEE.
- **Имена классов.** В SUO‑KIF имена классов — это идентификаторы без пробелов (например, `Automobile`, `LivingThing`). В Excel они останутся такими же. Если хочешь русские названия, их придётся добавить отдельным столбцом вручную или из словаря переводов.

## Как это связать с твоими задачами

- Для **Mermaid‑диаграмм**: CSV с колонками `ParentClass, ChildClass` — идеальный источник. Можно написать простой скрипт, который из CSV генерирует Mermaid‑код.
- Для **RDF/Turtle**: CSV можно превратить в Turtle-файл (например, через Python), чтобы получить `rdfs:subClassOf` связи.
- Для **сравнения с DOLCE/BFO**: в Excel удобно рядом с SUMO‑классами писать соответствующие классы из других онтологий и делать сводную таблицу.

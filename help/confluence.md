Официальное приложение Mermaid, разработанное создателями Mermaid.js. 
- Особенности: Включает встроенный визуальный редактор, генерацию диаграмм на основе искусственного интеллекта, подсветку синтаксиса и синхронизацию с облаком.

## 2

Чтобы разместить в общем публичном пространстве Confluence страницу со ссылками на страницы из частных пространств, которые открывались бы для всех, нужно использовать механизм **публичных ссылок (Public Links)**. Это функция Confluence Cloud, которая позволяет делиться отдельными страницами с людьми, не имеющими доступа к вашему Confluence, без необходимости делать публичным всё пространство целиком.

### 🔑 Ключевое различие: публичные ссылки vs. анонимный доступ

Прежде чем перейти к инструкции, важно понять разницу между двумя способами предоставления доступа:

*   **Публичные ссылки (Public Links)**: Позволяют открыть доступ **к отдельной странице** (или блогу, whiteboard) для любого человека в интернете. Ссылка работает, даже если страница находится в частном пространстве с ограниченными правами. Доступ не требует входа в Confluence.
*   **Анонимный доступ (Anonymous Access)**: Делает **всё пространство** (или несколько страниц внутри него) доступным для просмотра без входа в систему. Это более широкий и менее избирательный метод.

Для вашей задачи, когда нужно открыть доступ только к **конкретным страницам** из частных пространств, идеально подходят **публичные ссылки**.

### 📝 Пошаговая инструкция

#### Шаг 1: Убедитесь, что публичные ссылки разрешены на сайте
Администратор Confluence должен включить эту функцию глобально.
1.  Перейдите в **Администрирование Confluence** (иконка шестерёнки в правом верхнем углу).
2.  В левом меню выберите **Настройки** → **Безопасность** (или **Security**).
3.  Откройте вкладку **Публичные ссылки** (Public links).
4.  Убедитесь, что переключатель **«Разрешить публичные ссылки на этом сайте»** (Allow public links on this site) включён.

#### Шаг 2: Создайте публичную ссылку для каждой страницы из частного пространства
Эту операцию нужно повторить для каждой страницы, на которую вы хотите дать ссылку.
1.  Откройте нужную страницу в **частном пространстве**.
2.  В правом верхнем углу страницы нажмите кнопку **«Поделиться»** (Share).
3.  В открывшемся окне найдите опцию **«Публичная ссылка»** (Public link) и нажмите **«Создать публичную ссылку»** (Create public link).
4.  Система сгенерирует уникальный URL-адрес. **Скопируйте его**.
5.  При необходимости вы можете настроить срок действия ссылки или отозвать её в любой момент.

> **Важно**: Для создания публичной ссылки у вас должны быть права на редактирование страницы. Если вы не можете создать ссылку, обратитесь к администратору пространства.

#### Шаг 3: Разместите ссылки на странице в публичном пространстве
1.  Перейдите в ваше **общее публичное пространство**.
2.  Создайте новую страницу или отредактируйте существующую.
3.  Вставьте скопированные публичные ссылки в текст страницы. Они будут выглядеть как обычные веб-ссылки (например, `https://your-domain.atlassian.net/wiki/spaces/.../p/...`).
4.  Опубликуйте страницу.

#### Шаг 4: Обеспечьте доступность самой страницы в публичном пространстве
Чтобы все могли видеть страницу со ссылками, убедитесь, что она доступна анонимно. Это можно сделать двумя способами:
*   **Через анонимный доступ к пространству**: Администратор пространства должен включить анонимный просмотр для всего публичного пространства (Space tools → Permissions → Anonymous Access → All View).
*   **Через публичную ссылку на саму страницу**: Вы также можете создать публичную ссылку для этой страницы-агрегатора, как описано в Шаге 2. Тогда доступ к ней будет возможен по прямой ссылке.

### ⚠️ Ограничения и важные нюансы

*   **Ссылки только на текущие версии**: Публичная ссылка ведёт на **последнюю опубликованную версию** страницы. Если вы обновите содержимое, изменения сразу станут видны по ссылке.
*   **Ссылки внутри страницы**: Если на странице из частного пространства есть внутренние ссылки на другие страницы (без публичных ссылок), они не будут работать для внешних пользователей. Им нужно будет создавать публичные ссылки для каждой такой страницы отдельно.
*   **Безопасность**: Публичные ссылки не индексируются поисковыми системами, но любой, у кого есть ссылка, может просмотреть страницу. Относитесь к этому как к «доступу по ссылке» и не размещайте конфиденциальную информацию на страницах, для которых создаёте публичные ссылки.

### 💎 Итог

Использование **публичных ссылок** — это наиболее гибкий способ решить вашу задачу. Вы сохраняете частные пространства закрытыми, но даёте точечный доступ к нужным страницам через страницу-агрегатор в публичном пространстве.

### 2.1 on-premise
В Confluence Server (on-premise) **нет** встроенной функции «Публичных ссылок», как в Cloud-версии, поэтому единственный способ решить вашу задачу, не меняя права на самих страницах в закрытых пространствах, — это использовать сторонние плагины из Atlassian Marketplace.

Они работают по схожему принципу: создают для страницы специальный внешний URL-адрес (часто называемый public link или access link), который открывается без авторизации в Confluence. Вы можете просто вставить эти ссылки на страницу-агрегатор в вашем общем публичном пространстве.

### 🧩 Плагины для Confluence Server (on-premise)

Вот основные решения, которые стоит рассмотреть. Обратите внимание, что для Confluence Server поддержка многих плагинов прекращена или ограничена, поэтому нужно внимательно проверять совместимость с вашей версией.

**Comala Share It**
*   **Как работает:** Создает публичные ссылки на страницы и вложения, не требуя создания дополнительных пользователей или включения анонимного доступа.
*   **Ключевые особенности:** Работает как для страниц, так и для вложений. Есть возможность управлять ссылками на уровне пространства.
*   **Важное замечание:** Этот плагин **был официально отправлен на пенсию (retired) 15 апреля 2024 года**. Он может быть недоступен для новых установок или не поддерживаться на последних версиях Confluence Server.

**Secure Share for Confluence (miniOrange)**
*   **Как работает:** Позволяет создавать и делиться ссылками доступа к любым страницам Confluence, не требуя входа в систему.
*   **Ключевые особенности:** Предлагает расширенные функции безопасности, такие как защита ссылок паролем, установка срока действия, ограничение по IP-адресам и поддержка SSO. Совместим с Confluence Server 7.0.1 - 8.9.8.
*   **Плюсы:** Более современный и функциональный вариант, если Comala Share It недоступен.

**External Share for Confluence**
*   **Как работает:** Предоставляет возможность делиться страницами с людьми вне компании в реальном времени, без необходимости создавать гостевые аккаунты или покупать дополнительные лицензии.
*   **Ключевые особенности:** Поддерживает совместную работу, защиту паролем, срок действия ссылок, а также может делиться целыми структурами страниц (с метками или без).
*   **Важное замечание:** Для Confluence Server **продажи и поддержка этого плагина также прекращены**. Он может работать на версиях Server 9.0.0 - 9.0.3, но использовать его стоит с осторожностью.

**MultiExcerpt Enhanced Permissions (Appfire)**
*   **Как работает:** Этот плагин действует иначе. Он позволяет с помощью макроса **«вырезать»** определенный контент со страницы в закрытом пространстве и **«вставить»** его на страницу в публичном пространстве.
*   **Ключевые особенности:** Вы можете гибко настраивать, каким именно пользователям или группам будет виден этот вставленный контент.
*   **Когда подходит:** Это решение не создает прямую ссылку на оригинальную страницу, а **дублирует** её содержимое на публичной странице. Это может быть полезно, если вам нужно показать не всю страницу, а только её часть, и вы готовы смириться с тем, что контент будет дублироваться.

### 💎 Сравнение и итоговая рекомендация

| Плагин | Принцип работы | Статус для Server | Ключевая особенность |
| :--- | :--- | :--- | :--- |
| **Comala Share It** | Публичные ссылки на страницы/вложения | **Retired (2024)** | Больше не поддерживается |
| **Secure Share (miniOrange)** | Ссылки доступа с расширенной защитой | **Активен** (для версий 7.x-8.9.8) | Пароли, срок действия, IP-ограничения |
| **External Share** | Ссылки для внешних пользователей | **Продажи остановлены** | Совместная работа в реальном времени |
| **MultiExcerpt Enhanced** | Вставка контента с закрытых страниц | **Активен** | Дублирование контента, а не ссылка |

**Рекомендация:**

Учитывая, что вам нужно именно **дать ссылку** на существующие страницы, а не дублировать их содержимое, оптимальным выбором будет **Secure Share for Confluence от miniOrange**. Он специально разработан для создания внешних ссылок доступа и имеет все необходимые функции безопасности. Перед покупкой обязательно проверьте совместимость с вашей версией Confluence Server в документации плагина.

Если вы готовы к компромиссу в виде дублирования контента, то **MultiExcerpt Enhanced Permissions** — это рабочий и поддерживаемый вариант, который решает задачу через вставку содержимого.

### ⚠️ Важные моменты

*   **Доступность извне:** Для того чтобы созданные публичные ссылки работали, ваш сервер Confluence должен быть **доступен из интернета** (или из той сети, где находятся ваши пользователи). Если он находится только во внутренней сети, ссылки не будут открываться.
*   **Установка плагина:** Для установки любого плагина вам потребуются права администратора Confluence.
*   **Внутренние ссылки:** Если на странице, для которой вы создаете публичную ссылку, есть ссылки на другие страницы (без публичных ссылок), они не будут работать для внешних пользователей.

## 2
### Часть 1
 
Без плагина решить вашу задачу в Confluence Server (on-premise) невозможно. Это ограничение самой архитектуры безопасности Confluence, а не отсутствие какой-то скрытой настройки.

📌 Формулировка задачи
Дано:
- Confluence Server (on-premise).
- «Общее публичное пространство», доступное для просмотра всем (в том числе анонимным пользователям).
- «Закрытые пространства» с ограниченным доступом.
- Страницы в этих закрытых пространствах, которые должны быть доступны всем.

Жёсткое условие: свойства (права доступа) самих страниц в закрытых пространствах не должны изменяться.

Требуется:  
Разместить в общем публичном пространстве страницу-агрегатор со ссылками на страницы из закрытых пространств так, чтобы эти ссылки открывались для всех (включая пользователей без учётной записи в Confluence) без предоставления им доступа ко всему закрытому пространству и без изменения прав на самих целевых страницах.

🚫 Почему штатными средствами это не решается  
- Анонимный доступ работает только на уровне пространства. Confluence позволяет включить анонимный просмотр для всего пространства целиком (Space Tools → Permissions → Anonymous Access → All View). Отдельную страницу внутри закрытого пространства сделать публичной штатными средствами нельзя. Эта функциональность запрашивалась сообществом (тикет CONF-37884), но до сих пор не реализована.
- Права наследуются, но не могут быть расширены. В Confluence можно ограничить доступ к странице, но нельзя добавить права на страницу, если их нет у пространства. То есть, если у анонимных пользователей нет доступа к пространству, вы не можете выдать им доступ к одной странице внутри него.
- Ссылки не дают доступа. Простая вставка URL страницы из закрытого пространства на публичную страницу не сработает: при переходе по ссылке анонимный пользователь увидит либо страницу входа, либо ошибку прав доступа.

⚠️ Возможные обходные пути (и почему они не подходят)
 
| Обходной путь | Почему не решает задачу |  
|---------|--------------|
| Включить анонимный доступ ко всему закрытому пространству | Нарушает требование «не менять свойства страниц» и открывает всё пространство, а не отдельные страницы. |
| Создать гостевые учётные записи |	Требует лицензий, не работает для «всех» и противоречит идее публичного доступа. |
| Использовать внешний прокси или скрипт |	Технически сложно, ненадёжно, небезопасно и не является штатным решением Confluence. |
| Экспортировать страницы в HTML и разместить на другом сервере	| Теряется связь с Confluence, контент устаревает, требует ручной синхронизации. |


💎 Итог  
Задача может быть решена только с помощью сторонних плагинов категории Secure / External Share (например, Secure Share for Confluence от miniOrange или External Share for Confluence). Эти плагины генерируют для конкретной страницы уникальный внешний URL, который открывается в обход стандартной системы прав Confluence, не изменяя при этом свойства самой страницы. Без такого плагина — увы, никак.


### Часть 2

Tab Wizard и подобные решат задачу?

Нет, Tab Wizard не решит вашу задачу. Это плагин для оформления и навигации, а не для предоставления публичного доступа к страницам.

🎯 Для чего на самом деле нужен Tab Wizard  
Tab Wizard (входит в состав плагина Navitabs от Elevatic) — это инструмент для структурирования контента. Его основная функция — превращать существующие страницы Confluence (дочерние страницы, страницы с метками) или пользовательский контент в удобные вкладки, выпадающие списки или карточки.

Он помогает решить задачу навигации и визуального оформления внутри Confluence, например:

Создать единый хаб для документации отдела, где каждая вкладка ведёт на свою страницу.

Организовать онбординг-материалы в виде пошаговых вкладок.

Собрать на одной странице ссылки на страницы из разных пространств для удобства пользователей, у которых уже есть доступ к этим пространствам.

🚫 Почему это не решает вашу задачу  
Ваша задача — предоставить доступ к страницам из закрытых пространств для людей, у которых нет прав на эти пространства. Tab Wizard этого не делает.

Это не инструмент безопасности: Tab Wizard не создаёт внешних ссылок и не управляет правами доступа. Он лишь отображает контент, к которому у пользователя уже есть доступ в Confluence.

Нет функции «Публичных ссылок»: В нём нет возможности сгенерировать уникальный URL, который открывался бы без авторизации, в обход стандартной системы прав Confluence.

Работает в рамках прав Confluence: Если страница находится в закрытом пространстве, пользователь без прав не увидит её содержимое, даже если она встроена во вкладку Tab Wizard на публичной странице.

💎 Итог  
Tab Wizard — это отличный инструмент для оформления вашей страницы-агрегатора, но не для решения проблемы доступа. Его можно использовать на втором этапе, когда у вас уже есть публичные ссылки на нужные страницы: с его помощью вы красиво оформите эти ссылки в виде вкладок.

Для самой же задачи предоставления доступа по-прежнему необходимы плагины категории Secure / External Share (например, Secure Share for Confluence от miniOrange или External Share for Confluence), которые генерируют внешние ссылки доступа в обход прав Confluence.
